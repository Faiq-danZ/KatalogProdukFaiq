# Katalog Produk (JavaFX + SQLite)

## Cara Menjalankan Aplikasi

1. Pastikan **JDK (versi 11 atau lebih baru)** dan **Apache Maven** sudah terpasang di komputer.
2. Clone atau unduh repository ini, lalu buka folder proyek `KatalogProdukFaiq` menggunakan **Apache NetBeans** atau terminal.
3. Jalankan perintah berikut melalui terminal di direktori utama proyek untuk mengunduh dependensi dan menjalankan aplikasi:
   mvn clean javafx:run
